# Reddit Distribution — Finding Shopify App Makers

Captured: 2026-05-31. Context: ContentDesk's beachhead is Shopify app makers (see `STATUS.md`). This doc covers where to find them and how to approach.

## The Reddit Subs Where Shopify App Makers Actually Show Up

- **r/ShopifyDev** — the dev sub. Low AEO talk (confirmed by founder) but app makers *are* there discussing builds, App Store rejections, partner-API issues. Good for credibility-by-helping, not for cold offers.
- **r/shopify** — much bigger, mostly merchants — but app makers post launches and answer merchant questions. Higher discovery, lower density.
- **r/SaaS** — many indie SaaS founders self-identify; cross-section with Shopify app makers is real.
- **r/SideProject** — already validated for ContentDesk in Phase 2. Filter for Shopify-app launches and reply to those.
- **r/microsaas** and **r/EntrepreneurRideAlong** — adjacent indie/bootstrap density.
- **r/EcommerceMarketing** — mixed merchants/operators, occasional app maker.

## Three Tactical Patterns That Work Better Than Posting

1. **Search-then-comment.** Reddit search for `"I built a Shopify app"`, `"launched my Shopify app"`, `"looking for feedback Shopify app"`. Those are pre-qualified maker-posts. Comment with a substantive teardown observation, not a pitch. Same hook that worked in Phase 2, delivered one-to-one.
2. **Shopify App Store new-app feed → Reddit name match.** New apps launch publicly. Search the maker's name on Reddit — if they post, you have a warm context entry point.
3. **Answer the merchant pain in merchant subs.** When merchants in r/shopify or r/EcommerceMarketing ask "how do I get my new app discovered" or "any tips for App Store ranking" — answer with substance. App makers lurk those threads.

## The Flag Worth Naming

Shopify app makers don't live on Reddit as densely as B2B SaaS founders do.

Higher-density channels for this specific buyer:

- **X / Twitter** — Shopify dev Twitter is real and tight
- **Indie Hackers**
- **Shopify Partners Slack / Discord** communities
- **Shopify App Mafia** and app-maker peer groups

Reddit is a fine channel but probably won't be the highest-volume one for this vertical. If Phase 3's goal is conversion volume, build a multi-channel motion (Reddit + X + IH) rather than leaning Reddit-only like Phase 2 did.
