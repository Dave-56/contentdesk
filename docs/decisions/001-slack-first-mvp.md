# 001 — Slack-first MVP

**Decision:** The product interface is Slack. One front-facing Manager Agent in a Slack
thread; specialist agents run behind the scenes. No web dashboard for the MVP.

**Why:** Lean founders already live in Slack. A deterministic workflow with approval
buttons in-thread is faster to build and to adopt than a separate web app, and keeps founder
checkpoints minimal.

**Revisit when:** Founders ask for reporting/history views that don't fit a chat thread, or
when multi-brand management outgrows a single channel.
